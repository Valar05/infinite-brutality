# Boxcraft Judgment MCP

## Owner and boundary

The owner is the project-local `tools/boxcraft-judgment-mcp` package. It uses the legacy Infinite Brutality route corpus through an exact-token adapter and judges the current controller-kata scatter as a red specimen. It does not replace the runtime generator, infer missing structure, call a model, browse during generation, or write to Home Center.

Home Center's `PUNNETT — Saint Mendel Judgment Jar` is consumed read-only as the judgment contract: visible rails, declared crossings, the six-value ruling enum, corrigibility, and hard gates louder than averages. Each persisted run carries a source receipt proving that boundary.

## Atom

The first atom is the **Block**: a whole traversable sequence. WALK and LOOP grammars have a stable ordered trunk and an explicit recovery branch. A mandala is the first centering pressure, not a decorative style command. The center motif occupies the Block sequence without changing its traversal identity; the Block itself remains the atomic design unit.

## Controller axis

Every candidate is rendered and judged at 101 integer samples:

`0 MODERN_WAR -> 100 QUAKE_ANIME_BULLSHIT`

Ground speed, acceleration distance, gap/rise limits, air control, recovery width, and satellite authority use published formulas. Satellite marks are dormant below their genotype threshold and active above it. The ordered sequence and its core hash cannot change anywhere on the axis. Each pressure pack carries explicit source references in `src/catalog.mjs`; those references are provenance only and are never fetched by generation.

## Prompt contract

Use the MCP prompt `new_block` or submit exact `BLOCK REQUEST 1` text to `compile_block`/`generate_block`. Generation uses a seeded FNV-1a + Mulberry32 stream; `Math.random`, network calls, and model inference are absent. Population selection sorts by hard failures, worst-axis score, mean score, complexity, then stable genotype hash.

Artifacts are written beneath `generated/boxcraft_blocks/v1/<id>/<digest>/`. Each run includes every candidate map and controller pipe for all 101 points, `run.json`, `judgment.json`, `manifest.json`, and `source-receipt.json`.

## Verdict semantics

- `REJECT`: at least one hard gate failed; scores cannot overrule it.
- `UNKNOWN`: input or legacy token was not declared.
- `OBSERVE`: structurally valid, but controller endpoint feel still lacks measured player evidence.
- `PROCEED`, `REVISE`, and `UNCLE` remain available Punnett rulings but are not fabricated by the current structural judge.

The legacy straight lip bridge is an exact adapter acceptance specimen. The existing deterministic scattered-box controller arena is intentionally rejected for missing authored sequence identity, pressure provenance, and full-axis scaling.

# Punnett Boxcraft Judgment MCP

Project-local, prompt-driven deterministic selection for Infinite Brutality Block recipes.

A **Block** is one complete traversable sequence, not a room, tile, platform, or isolated encounter. `BLOCK REQUEST 1` is the only generation input. Unknown fields, atoms, route tokens, metrics, or pressure packs return `UNKNOWN`; the engine never repairs prose or guesses intent.

Each candidate is evaluated at every integer point on `MODERN_WAR (0) -> QUAKE_ANIME_BULLSHIT (100)`. The core sequence hash must remain identical. Only realization parameters and optional satellites may scale. Every candidate/axis realization is stored as a `BLOCKMAP 1` ASCII map and a `PIPE 1` controller envelope.

Punnett's rules are explicit: visible rails, no secret weights, and hard gates outrank averages. Passing structural generations return `OBSERVE` until endpoint controller feel has measured evidence. The Home Center Drive source is read-only and is recorded in each run's `source-receipt.json`; this project never appends to Home Center.

Run `npm test` and `npm run smoke` here, or run `sh ../test_boxcraft_judgment_mcp.sh` (Android shared storage is mounted no-exec).

## Fleshpunk asset gate

`ASSET REQUEST 1` binds every candidate to `data/fleshpunk_asset_targets.json`. P0 machinery and creatures must retain their declared pipes, valves, tendons, connective tissue, host surface, support chain, service route, collider, interaction, silhouette, and assembled/exploded/orthographic views. Unknown targets stay `UNKNOWN`; changed or missing production anatomy is `REJECT`. RegNet may approve an internal mutation, but the public verdict remains `OBSERVE` until the user accepts fresh cloud/Sense pixels.

Run `npm run canary` to emit the eight deterministic P0 SVG plates and strict request/candidate sidecars.
